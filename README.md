# College ERP Lite

A complete College ERP System built using Python, Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- Student Management
- Course Management
- Attendance System
- AI Attendance
- Fee Management
- Result Generation
- Report Card Printing
- College Settings

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
